# 📁 File Organizer

A simple Python automation tool that automatically organizes files into folders based on their file types.

## Features

- Automatically sorts files
- Creates folders automatically
- Supports images, documents, videos, music and code files
- Moves unknown files to an `Others` folder
- Lightweight and easy to use

## Technologies

- Python 3
- os
- shutil

## How It Works

The program checks the file extension and moves the file into the appropriate folder.

Example:

```text
photo.jpg → Images
resume.pdf → Documents
song.mp3 → Music
video.mp4 → Videos
program.py → Code
